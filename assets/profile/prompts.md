# 프로필 사진 프롬프트

https://aistudio.google.com 에서 이미지 모델을 고르고 아래를 그대로 붙여넣으세요.
가로세로 비는 1:1 로 두고, 받은 파일은 이렇게 다듬습니다:

    python -m agent avatar --import 내려받은파일.png

색 기준: design/tokens.json (color/bg=#0b0d10, color/accent=#7c5cff, color/accent-soft=#a68dff, color/accent-2=#22d3ee)

## 급상승 별 (`star-surge`)

```
A flat vector app icon on a square canvas. Centered subject: a single bold five-pointed star, geometric with slightly rounded tips, tilted a few degrees, with two short motion streaks trailing down-left to suggest it is rocketing upward.

Style: modern developer-tool branding, flat 2D vector illustration, crisp geometric shapes, thick confident strokes, one subtle smooth gradient on the main shape only. No photorealism, no 3D render, no bevel, no drop shadow, no glossy highlight.
Palette, use these exact colors: background solid #0b0d10; main shape gradient from #7c5cff to #a68dff; a single small accent detail in #22d3ee. No other hues.
Composition: one subject only, perfectly centered, occupying about 60 percent of the canvas with generous empty margin on all four sides so nothing is clipped when the image is cropped into a circle. Flat solid background edge to edge, no frame, no border, no rounded card behind the subject.
It must stay instantly readable when scaled down to 40 pixels: high contrast, no thin lines, no fine detail, no texture, no pattern.
Absolutely no text, no letters, no numbers, no words, no lettering, no watermark, no signature, no people, no faces, no hands.
```
